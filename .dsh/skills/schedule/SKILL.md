# 日程 CLI

本插件的 Agent 接口不是常驻工具，而是 `schedule` CLI。命令细节随插件在线提供，按需发现；本 skill 只保留发现顺序与跨命令行为底线。

## 发现顺序

1. 先运行 `schedule --help`，看当前命名空间与指南目录。
2. 进入某一层：`schedule <命令> --help`；叶子命令的帮助才是参数与副作用的权威说明。
3. 较长教程用 `schedule guide <主题>`；主题列表在顶层帮助里。
4. 来源插件会贡献自己的命名空间与指南；只使用当前帮助里实际存在的命令。

命令不在 `PATH` 时，用宿主生成的启动器：`~/.dsh/schedule-cli/schedule`（Windows 为 `schedule.cmd`；`DSH_HOME` / `SCHEDULE_CLI_HOME` 可覆盖目录）。

## 执行规则

- 只通过 CLI 操作日程；不要读取或搜索宿主内部存储、配置或凭据，也不要用文件或 HTTP 旁路补齐。类别/颜色、学期起点、提醒配置等设置项引导到日程设置。
- 写入/修改/删除/完成复用本会话回执中的真实 `id`；成功回执即写入确认，不重复查询验证。
- 用户未明确要求时，不要额外创建任务或提醒，也不要自定提醒提前量、优先级；可以询问是否需要。
- 外部通知已确定时间的课程、考试、竞赛、预约等建议加 `--lock`；可调整计划默认不加。
- 通知只给“某日起可查询/开放”时，不要编造任务截止时间；先问具体提醒时间，或只写入备注。
- 参数、冲突重试、时间格式、批量输入、来源密码等细节，以对应 `--help` 或 `guide` 为准。
